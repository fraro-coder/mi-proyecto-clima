# Monitor Climático Profesional

## Stakeholder
agencia de turismo y au pairs que viene de diferentes partes del mundo a vivir experiencias unicas.

## Problema
Necesitan conocer condiciones climáticas reales para planificar rutas, actividades y saber que estilo de oufits traer para la epoca en la que vienen .

## Solución
La aplicación consulta datos meteorológicos en tiempo real usando OpenWeather API.

## Variables de entorno necesarias

API_KEY_PROYECTO

## Ejecución local

export API_KEY_PROYECTO="tu_api"

python3 app_clima.py

## Ejecución Docker

./build.sh
